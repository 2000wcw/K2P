今天比较空，看到很多不懂机场底层逻辑的，我来详细解释一下为什么机场会说自己被通告了。

如果把GFW比喻成一座大桥上的检查站，你浏览外网的数据包比做桥上通行的车辆，机场是派出这些车辆的运输公司，那么通告的意思就是警告运输公司，你进出检查站的车辆拉了违规品，这些违规品就是访问被GFW封禁网站的数据包，如果无视通告，那么检查站分分拦下你的数据包并取消你的通行权，也就是你的机场被封了。很多机场用户会说，我之前用了那么久没事，怎么这几天出了问题？这就要说到机场的前世今生了。

说回这座大桥上的GFW检查站，最开始的时候，这座大桥上每天都有各种海量车辆也就是数据包来来往往，有私人的，有企业的，但是大桥容量有限，所以经常容易引起拥堵，就是延迟高了，卡顿了，对私人来说反正就是视频稍微卡一点，网页刷新慢一些，等一等无所谓。但是对于要赚钱的企业来说，尤其是金融领域和互联网领域的大企业，这些卡顿和延迟就是对赚钱最大的威胁，怎么办？简单，加钱！

有钱的国际大企业就直接在桥上修一条自己的专用道，只供自己用，比如微软、甲骨文、苹果等等，这些企业家大势大，有些甚至是领导人直接引进的，GFW不敢得罪，只能放行，当然，这些大企业也会签个承诺书，承诺不会在这条专用道上运送违禁品，这就是企业跨国专线的由来，这些专线因为签了承诺书，是不需要过GFW检查站的，所以速度飞快，效率拉满，不过呢，价格也相当的昂贵，毕竟专用通道。一般人根本用不起。

又过了一阵子，国内有海外业务的大企业看到跨国大企业的专用道好用又快捷，便想着法子也托关系修几条自己的专用通道，这些企业有的是国企，有的是央企，还有的就是GFW关联企业，来头都不小，所以呢也都一一放行，当然，承诺书也是必须签的，也会定期检查。这些企业申报专线的时候往往会往大的方向报，反正不花自己的钱，带宽大一点也好，但是呢，实际使用中，申报的500M带宽，只使用了200M带宽甚至不到200M，那么多余的带宽不就浪费了？
聪明的看官肯定看懂了，这里就是中转机场出现的契机，这些大企业的专线带宽利用率不高，剩余带宽不用就是白白浪费了，所以对跨国专线极度需求的机场主就出现了，这个东西不需要过GFW，速度又快，非常之香！不过呢，一分钱一分货，价格肯定也不便宜。这种情况慢慢发展下去，到后来很多中小企业都开始申请专线了，就为了搞这个业务，毕竟机场主钱多事少，大家都喜欢，这也成了行业内的潜规则了。

所以，各位知道现在通告的含义了吧？通告的是这些企业申请的专线，具体到细节上就是专线机房，一般数据中心都是很大的交换中心，成百上千台服务器，有些是大企业自己买的，有些是租用的，反正机场主是各显神通能搞定那种就搞定那种，从表面上，机房里面没有任何机场的存在，只有各大企业的专线服务器，但是机房内的管理层都清楚谁的专线在跑什么业务，毕竟白花花的银子都喜欢，但是这次因为某些原因，上面要求必须一刀切，没办法，只能拔线。
